Приёмка этапа 5:
1) Все финансовые операции выполняются в финтехе, DWH в них не участвует.
2) Сверка остатков по счетам и кредитам DWH и финтеха - ноль расхождений.
3) Параллельная работа месяц: операции в новой системе, сверка с DWH ежедневно.
4) Отчётность ЦБ сформирована из новой системы и совпадает с отчётностью из DWH.

Условия перевода SQL Server в режим чтения (этап 7):
1) Этапы 4 и 5 приняты: медданные и операционные данные финтеха перенесены.
2) Все маршруты ESB, которые пишут в DWH, переключены.
3) Две недели нет операций записи в SQL Server, кроме сверочных (по аудиту БД).
4) Решение принимают архитекторы с владельцами доменов клиник и финтеха. Откат - возврат записи в DWH до приёмки.

Сквозные меры для медицинских и финансовых сервисов:
1) Параллельная работа старого и нового интерфейса клиник до приёмки.
2) Сверка данных SQL Server и новых БД на каждом шаге миграции.
3) Резервирование и геораспределение БД клиник и финтеха с этапа 2.

## Обоснование

1) **Архитектура и домены.** Без границ и владельцев каждая команда снова пойдёт дорабатывать DWH. Дешёвый этап, снимает риск переделок.
2) **Облачная основа.** Без сетей, IAM и Kafka нельзя изолировать медданные и запускать домены. Снижает затраты на железо, даёт масштабирование.
3) **Платформа данных MVP.** Первый видимый результат для бизнеса: отчёты за секунды вместо часов. Начинаем с финтеха и корпоративного домена — там нет медданных, риск минимальный.
4) **Выделение клиник.** Самый рискованный этап, поэтому после того, как платформа обкатана. Снимает регуляторный риск и единую точку отказа.
5) **Перенос финтеха из DWH.** Аналитическая копия не выполняет финансовые операции. Без переноса логики перевод DWH в режим чтения остановит платежи и кредиты. Параллельно с клиниками - разные команды.
6) **Самообслуживание.** Сотрудники строят отчёты сами, без очереди к аналитикам. Ускоряет управленческие решения.
7) **Вывод легаси.** Снимает затраты на поддержку и риски ИБ. Новые бизнесы подключаются по шаблону, без доработки DWH. Начинается только после приёмки этапов 4 и 5.
