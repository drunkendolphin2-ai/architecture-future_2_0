# Как пользоваться радаром

Радар технологий компании «Будущее 2.0».

Версии:
1) **2026-10-01** — текущее состояние.
2) **2026-10-31** — целевое состояние после трансформации.

Кольца:
1) **Активно используем** — стандарт для новых проектов.
2) **Пробуем** — пилот на одном-двух доменах.
3) **Изучаем** — оцениваем под конкретную задачу.
4) **Выкидываем** — новые проекты не начинаем, выводим.

У каждой технологии указаны бизнес-сценарии, которые она поддерживает. Радар пересматривается раз в квартал, изменения — через пул-реквест.
